# Анализ данных проекта «Карта ДТП»

## 📋 О проекте

«Карта ДТП» — некоммерческий проект, посвящённый проблеме 
дорожно-транспортных происшествий в России. Цель проекта — повысить 
безопасность на дорогах: выявлять реальные причины ДТП, оценивать уровень 
развития инфраструктуры и разрабатывать качественные решения и программы 
по повышению безопасности на улицах и дорогах.

Заказчик хочет собирать данные более высокого качества и ожидает 
рекомендаций: на какие проблемы и особенности обратить внимание.

В рамках проекта проведён исследовательский анализ данных о ДТП 
в **Кировской** и **Московской** областях: проверка качества данных, 
анализ динамики происшествий и сравнение групп водителей по стажу.

> ⚠️ Данные проекта носят справочный характер и используются 
> исключительно в исследовательских целях.

## 🎯 Цели исследования

- Проверить наличие пропусков и дубликатов в данных
- Оценить корректность типов данных и дать рекомендации по их изменению
- Проанализировать, как менялось число ДТП по временным промежуткам
- Выяснить, различается ли число ДТП для групп водителей с разным стажем
- Сформулировать рекомендации заказчику по сбору более качественных данных

## 📊 Данные

**`Kirovskaya_oblast.csv`**, **`Moscowskaya_oblast.csv`** — информация о ДТП:
- `geometry.coordinates` — координаты ДТП
- `id` — идентификатор ДТП
- `properties.tags` — тег происшествия
- `properties.light` — освещённость
- `properties.point.lat` / `properties.point.long` — широта и долгота
- `properties.nearby` — ближайшие объекты
- `properties.region` — регион
- `properties.scheme` — схема ДТП
- `properties.address` — ближайший адрес
- `properties.weather` — погода
- `properties.category` — категория ДТП
- `properties.datetime` — дата и время ДТП
- `properties.injured_count` — число пострадавших
- `properties.parent_region` — область
- `properties.road_conditions` — состояние покрытия
- `properties.participants_count` — число участников
- `properties.participant_categories` — категории участников

**`Kirovskaya_oblast_participiants.csv`**, **`Moscowskaya_oblast_participiants.csv`** — сведения об участниках ДТП:
- `role` — роль
- `gender` — пол
- `violations` — нарушенные ПДД
- `health_status` — состояние здоровья после ДТП
- `years_of_driving_experience` — число лет опыта
- `id` — идентификатор ДТП

**`Kirovskaya_oblast_vehicles.csv`**, **`Moscowskaya_oblast_vehicles.csv`** — сведения о транспортных средствах:
- `year` — год выпуска
- `brand` — марка
- `color` — цвет
- `model` — модель
- `category` — категория
- `id` — идентификатор ДТП

## 🔍 Этапы работы

### Шаг 1. Проверка ошибок в данных и предобработка
- Замена названий (меток) столбцов на оптимальные для работы
- Проверка пропусков (на примере `Kirovskaya_oblast.csv`): в каких столбцах 
  встречаются, предполагаемые причины, рекомендации по обработке и 
  предотвращению в дальнейшем
- Поиск явных и неявных дубликатов; доля явных дубликатов; проверка 
  уникальности идентификаторов
- Проверка корректности типов данных и рекомендации по их изменению

### Шаг 2. Исследовательский анализ данных (EDA)
1. Число ДТП по дням недели
2. Число ДТП по месяцам
3. Выделение категорий водителей по стажу (по датафрейму участников) 
   и сравнение числа ДТП между категориями

### Шаг 3. Дополнительная задача (⭐)
- Анализ числа аварий по годам в Кировской и Московской областях 
  (город Киров включён в область, Москва исключена)
- Сравнение областей в относительном выражении — на 100 тысяч жителей

### Шаг 4. Итоговый вывод и рекомендации
- Общий обзор проделанной работы
- Главные выводы по исследовательским вопросам
- Рекомендации заказчику по сбору более качественных данных
